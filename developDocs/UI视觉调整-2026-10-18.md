# UI 视觉调整 · 2026-10-18

本轮在已有功能上调整视觉与交互，不扩展云端适配器。共享工作区中已有的输入法修复保持原样。

## 视觉

- 首页改为集中展示考勤的工作台：日期、登记进度、在册成员、今日请假、待登记及主操作位于同一区域。圆环显示登记进度，已确认请假不进入应登记或已登记计数。
- 主按钮使用 `#2864E8`，深色链接及选中态使用 `#709CFF`。普通图标与设置入口使用中性灰；请假和异常继续使用语义色。
- 深色背景保持 `#101010`；内容卡片 `#1C1C1E`，面板 `#202022`，面板选项分组 `#29292C`。浅色背景为 `#F5F6F8`。
- 页面标题由 34 调整为 30，二级标题和分区标题统一为 17，减少过重的字形和空白。
- 底部四栏保持「首页 / 记录 / 同步 / 设置」。玻璃导航使用 28 sigma 模糊、方向性高光、可辨识的边缘和独立中性选中层；所有栏目的图标尺寸一致。
- 圆形顶部按钮增加渐变高光、细描边和外阴影。关闭毛玻璃后停止实时模糊并使用不透明背景。
- 首页空状态改为紧凑列表卡片，保留添加人员入口；统计和管理员通知仍位于首页下方。
- 设置入口去除多色图标，外观选项增加当前项勾选与图标；说明文字独立排列，移除卡片内嵌预览。

## 底部面板

- 从底部完整滑入，两侧各留 8，宽屏最大宽度 640。
- 选项使用同一圆角列表分组、左侧图标、文字和内缩分隔线，单行最小高度 62；标题与底部按钮固定，列表独立滚动。
- 无图标的选项不保留空图标列。禁用项不可选择；当前选项显示勾选。
- 最大高度根据键盘上方可用空间计算，避免键盘与面板叠加后遮挡底部操作。

## 状态文案

首页默认展示今日登记人数，也可切换为待上传变更数量。没有待上传变更不再表示云端已经同步。同步页通过实际地址判断是否配置存储，并明确区分本地保存和云端同步。
