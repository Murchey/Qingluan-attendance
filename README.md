# 青鸾考勤

Android 优先的 Flutter / Cupertino 考勤客户端。支持离线登记、请假管理、数据统计与双通道通知，云端文件同步适配器仍在后续里程碑。

## 已实现

- 首页 / 记录 / 同步 / 设置四页，支持点击和拖动胶囊导航，横向页面切换。
- 首页展示本地记录总数、今日记录、启用人员、待上传变更与今日请假；提供今日登记、批量登记、补录历史（日历板选日）、请假记录入口，以及底部的「数据统计」与「管理员通知」入口。
- 人员新增、编辑、停用，Excel（.xlsx）与 UTF-8 CSV 名单导入预览，提示重名和缺失姓名；仅新增，不覆盖已有数据。
- 单人 / 批量登记、签到签退时间选择、状态、备注、作者与操作历史。
- **请假记录**：按人登记请假区间、类型、状态与原因；已确认请假当天考勤不可登记（数据层拦截），只能修改请假状态与时间；待确认 / 已取消不占用登记。
- **数据统计**：今日请假人数、区间请假人数与天数（本周 / 本月 / 本年 / 自定义），月历板把请假日期标红，点按日期查看当天请假成员，并显示请假类型分布。
- **考勤分统计**：按当前统计区间计算每人的考勤分，从基准分扣除已确认请假天数（事假、病假等）与迟到 / 早退 / 缺勤次数；每类场景的默认扣分值可在统计页「扣分规则」或设置中修改，保存后立即重算，最低为 0 分，点按成员可查看扣分明细。
- 历史查询：日期范围 / 人员 / 状态 / 修改人筛选，姓名和备注搜索；详情编辑和删除（保留墓碑）。
- Excel 导出：当前筛选范围、可选字段、导出来源说明；Android 使用系统分享，桌面选择保存位置。
- 同步状态与待上传队列，字段级表格 diff（本地 / 远端 / 一键合并）、合并审计；远端快照由后续适配器注入。
- **通知**：启动 / 回前台时请求 `index.json`，仅当管理员通知（`note.md`）或开发者通知（`dev-note.md`）版本变化时才下载正文，并在自研底部面板渲染 Markdown；已读版本与最近检查结果写入本地；可在设置里关闭自动检查。
- **管理员通知发布**：内置「今日考勤情况」「调休计划」模板，生成 `note.md` 内容进入待上传队列，本地预览；签名上传接入后自动写入存储桶。
- **自研底部面板**：统一的圆角可滚动面板，承载选项、输入、日历与 Markdown 通知；圆形玻璃按钮、磨砂导航栏与「毛玻璃效果」开关（关闭后导航栏与浮动按钮改为不透明，不再实时模糊）。
- 深色模式使用 `#101010` 纯色背景，主题色为设计文档要求的藏青色：填充按钮统一深藏青 `#172A46`，深色模式下文字与描边取浅藏青 `#A8C2E0`；只在主要操作与选中态出现；顶部标题栏为渐变磨砂（模糊 + 页面色蒙版 + 纵向 alpha 渐变），内容滚动时从标题下柔和淡出。
- SQLite 持久化人员、记录、请假、通知状态和待上传标记，首次启动无示例业务数据。

## 尚待业务适配器接入

- OSS / COS / S3 签名鉴权与上传（含通知 `note.md` / `index.json` 的写入）、远端 manifest、分片快照上传下载和同步重试。
- 账号注册与管理、设备令牌与预签名 URL（见 `developDocs/云同步与服务端设计.md`）。
- 互联网北京时间请求。目前使用本地时钟计算东八区日期，并显示本地回退状态。
- GitHub / Gitee / 自建服务的实际版本检查、下载、校验与安装。目前保存更新源配置并展示待接入说明。
- 当前 SQLite 使用 schema v1 的工作区快照表服务 UI，尚未实现按日 SQLite 文件分片、加密及正式迁移。
- Flutter Windows runner 可用于界面开发预览；独立 Electron 客户端尚未创建。

OSS / COS 仅需填写原生存储桶 HTTPS 直链，桶名与区域地址由程序解析；S3 仍分别填写 Endpoint 与 Bucket。三种模式仍需访问密钥。切换服务时直链独立保留；旧的云厂商 Endpoint + Bucket 配置可自动识别。暂不支持自定义域名、文件下载链接或带签名参数的链接。

同步、更新按钮不会将未完成的服务请求展示为成功。连接测试检查 OSS / COS 存储桶直链或 S3 Endpoint 的连通性，不代表密钥和存储桶授权有效。

## 运行与检查

```bash
flutter pub get
flutter run -d emulator-5554
flutter run -d windows
flutter analyze
flutter test
flutter build apk --debug

# 界面检查用演示数据（人员 / 记录 / 请假 / 通知），默认关闭
flutter build apk --debug --dart-define=DEMO_SEED=true
```

测试覆盖：导航和拖动、小屏深色布局、批量登记、冲突决议、导入校验、Excel 内容、东八区边界、SQLite 重启恢复、请假拦截与统计、考勤分规则与重算、通知版本比对与面板渲染、Markdown 解析。

开发文档见 `developDocs/开发方案补充.md`、`developDocs/Android首版UI实现说明.md` 和 `developDocs/云同步与服务端设计.md`。
