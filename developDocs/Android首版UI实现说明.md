# Android 首版 UI 实现说明

## 本次边界

实现 UI 规划中的本地使用闭环，云端与自动更新以明确的未接入状态展示。没有生产示例名单、伪造同步成功记录或假的网络时间。

## 页面与数据

- `AppShell` 管理四页横向切换，胶囊选中态跟随手指位置。`Workspace` 是可注入、可监听的本地状态容器，生产启动打开 SQLite，测试使用隔离内存状态。
- 首次登记要求本地显示名。稳定 UUID 设备标识和显示名写入审计信息；这是作者标记，不等价于可信数字签名或账号认证。
- 人员使用稳定 UUID，停用保留历史。每人每天一条登记；重复登记需确认覆盖。删除使用墓碑，重新登记复用原记录 ID。
- 持久化当前采用 schema v1 单行 JSON 工作区表。未来按日分片是同步适配层工作，本轮不把活跃 SQLite 文件直接上传。
- `remoteEntries` 是后续 manifest 下载适配器提供的只读候选快照。冲突页保留两侧字段和作者，逐字段选择；一键合并采用字段时间较新的一侧，相同/缺失时间保留本地，删除状态也按独立字段处理。
- 合并确认后仅更新本地记录和待上传队列；未接入上传器时不会提交云端。合并保留稳定 ID、来源字段时间、双方审计历史和本次操作者。

## 文件和密钥

导入支持第一张工作表 .xlsx 或 UTF-8 CSV，首行为“姓名”（也接受 name / 人员），同名和空姓名逐行提示并跳过，其余名单确认后新增。暂不处理旧版 .xls。

导出遵循当前搜索与筛选结果，可勾选列。所有单元格以文本写入，避免姓名/备注被识别为公式；第二张表记录应用、生成时间、记录数和时区规则。

两项对象存储密钥独立写入 flutter_secure_storage，不保存在 SQLite 和导出文件。Endpoint 网络探测仅返回 HTTP 状态；不发送密钥，不冒充完整鉴权测试。

OSS / COS 的配置界面简化为“存储桶直链”：接受各自官方桶域名的 HTTPS 根地址，自动解析桶名和区域 Endpoint，拒绝文件路径、签名参数与含凭证的地址；S3 保持 Endpoint + Bucket。分别保存 ossBucketUrl / cosBucketUrl，避免服务切换覆盖；兼容识别已有 Endpoint + Bucket 配置。连通性测试直接访问当前桶根地址，不再访问区域 Endpoint。密钥填写方式保持不变。

## 自适应和验证

首页移除月历，展示本地有效考勤条数（不含删除墓碑）、东八区今日记录数、启用人员数与待上传变更项数。快捷入口支持选人登记、批量登记、选择日期补录和历史查询；下方展示最近修改的五条记录。今日登记会预选人员，已有当日记录时直接编辑。首页概览与快捷入口在可用宽度达到 720 时切为双栏，窄屏 diff 可横向滚动。

毛玻璃在用户关闭、系统禁用动画/无障碍导航时降级；运行中跳过前 30 帧后，在前 90 帧累计至少 15 帧栅格化耗时超过 24ms 时本会话降级，不影响业务状态。

运行 flutter analyze、flutter test 与 Android debug 构建。原生文件选择/分享、系统安全存储建议继续在目标真机进行人工验收；当前自动化覆盖本地业务、导入导出数据和 UI 操作。
