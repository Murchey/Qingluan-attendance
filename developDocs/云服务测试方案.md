# 云服务测试方案

## 范围

覆盖腾讯云 COS 配置解析、配置持久化、密钥安全存储、连接测试、同步状态展示、对象路径生成、离线待上传标记，以及 Android 重启后的数据恢复。

## 测试数据

- COS 直链：`https://demo-1250000000.cos.ap-guangzhou.myqcloud.com`
- 非法地址：HTTP、带路径、带查询参数、缺少 appid 后缀、非腾讯云域名
- 业务数据：3 名人员、1 条正常考勤、1 条请假、1 条通知草稿、删除后再编辑的记录
- 边界数据：空身份、跨日请假、重复确认请假、无网络和 HTTP 403 的 COS 桶

## 执行与判定

1. `flutter analyze` 与 `flutter test` 必须通过。
2. 在 Android 设置中保存 COS 直链与两项密钥，重启应用后地址仍存在，密钥不出现在业务导出和日志中。
3. 连接测试对可访问桶返回 HTTP 状态，并明确提示这不是权限验证；不可达地址在超时后返回失败提示。
4. 新增/修改/删除人员、考勤、请假和通知后，同步页显示待上传项；无配置或配置损坏时显示未配置。
5. 当前版本尚未接入 COS 上传下载适配器，因此同步上传下载属于阻断项，不能判定为通过。

## 本轮结果

静态检查与现有单测通过。ADB 真机安装被设备的“应用安装拦截”策略拒绝，无法完成 UI 回归；已补充 COS 地址边界回归测试，并修复旧版本可能留下的非法直链被误判为已配置的问题。
