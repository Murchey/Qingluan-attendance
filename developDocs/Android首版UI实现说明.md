# Android 首版 UI 实现说明

## 本次边界

实现 UI 规划中的本地使用闭环（考勤、请假、统计、通知），云端数据上传与自动更新以明确的未接入状态展示。没有生产示例名单、伪造同步成功记录或假的网络时间。

## 视觉与组件

- 背景为纯色：深色 `#101010`，浅色 `#F4F5F7`，不再使用渐变或底纹；对比度全部来自卡片与玻璃表面本身。
- 主题色按需求文档使用**藏青色**：浅色 `#172A46`，深色取浅藏青 `#A8C2E0`（深色下深藏青作填充不可读，故取同色相浅阶）；只用于主要操作、选中态描边与少量强调，图标、次级按钮、导航项仍是灰白 / 黑白色阶。填充型主按钮（`PrimaryButton`）在两种模式下都用深藏青 `#172A46` 填充：深色页面里若改用浅色强调色会变成一整块"系统蓝"，反而廉价。
- 顶部标题栏是**渐变磨砂**（移植自 AiChatApp 的 `_GlassSettingsHeader`）：整条标题栏铺一层 28px 高斯模糊 + 页面色 97% 蒙版，再用 `ShaderMask` 施加纵向 alpha 渐变（上 66% 完全不透明，向下过渡到全透明）。内容从标题下滚过时是逐渐淡出，而不是被硬边裁切或透出一块色斑；标题栏高度为状态栏 +96（根页）/ +56（二级页）。
- 页面顶部的圆形按钮同样移植自 AiChatApp：`ClipOval` + 12px 模糊 + 65% 的 `raised` 填充 + 1px 次级文字色 25%/32% 描边，不使用投影——描边才让它看起来像一片玻璃。
- 磨砂玻璃同样用于底部浮动导航（见下方参数表）。
  - 胶囊高 64、左右留 16、距安全区 8，圆角 = 高度一半；
  - `BackdropFilter` 模糊 sigma 22，底色用抬升表面色并取 58%（深色）/ 70%（浅色）透明度；
  - 描边为语义 outline（深 `#2E2F32` / 浅 `#D1D1D6`）@42%，宽 0.6；
  - 一层柔和投影：黑色 28%（深）/ 12%（浅），blur 18，offset (0, 6)；
  - 选中态是**独立的药丸**：底色 82% / 86%、主题色描边 32% / 24%、自带 blur 10 + offset(0,2) 的投影，圆角 24、内缩 4；
  - 不使用整块白色渐变高光，也不做饱和度后处理——这两项正是"塑料感"的来源；
  - 图标 21/22、字号 10、按下缩放 0.94，指示器跟随 PageView 连续移动。
- 「毛玻璃效果」开关默认开启。关闭后浮动控件改为不透明纯色，完全不创建 `BackdropFilter`（顶部标题栏仍保留 alpha 渐变，但没有模糊），用于降低功耗与栅格化开销；系统开启「减弱动态效果」或无障碍导航时自动降级。
- 列表起始位置按标题栏高度预留，静止时首项不会被标题遮挡；滚动后内容从渐变蒙版下淡出。
- 自研底部面板 `showAppSheet` / `SheetPanel`：28 圆角、拖动把手、固定标题、可滚动内容与固定底部操作区，替代系统 `CupertinoActionSheet`。选项行支持图标、说明、禁用态与勾选，供人员选择、状态选择、输入、日历与 Markdown 通知共用。
- 月历板 `CalendarBoard`：周一开头、可翻月、今日描边、请假日期红色标记、单日与区间两种选择方式。

## 页面与数据

- `AppShell` 管理 首页 / 记录 / 同步 / 设置 四页横向切换，胶囊选中态跟随手指位置。`Workspace` 是可注入、可监听的本地状态容器，生产启动打开 SQLite，测试使用隔离内存状态。
- 首次登记要求本地显示名。稳定 UUID 设备标识和显示名写入审计信息；这是作者标记，不等价于可信数字签名或账号认证。
- 人员使用稳定 UUID，停用保留历史。每人每天一条登记；重复登记需确认覆盖。删除使用墓碑，重新登记复用原记录 ID。
- 请假记录：`Leave{personId, startDay, endDay, type, status, reason}`，状态为 已确认 / 待确认 / 已取消。只有 `已确认` 在数据层（`saveEntries`）阻止当天登记，UI 在人员选择器中把请假人员置灰并提供「编辑请假」。重叠的确认请假会被拒绝。
- 数据统计页：区间筛选（本周 / 本月 / 本年 / 自定义）、今日请假、区间请假人数与天数、请假日历、今日请假成员、类型分布。
- 首页补录历史使用同一日历板选日期（上限为今天），请假日期标红。
- 持久化当前采用 schema v1 单行 JSON 工作区表（新增 `leaves` 与 `notices` 字段，无需迁移）。未来按日分片是同步适配层工作，本轮不把活跃 SQLite 文件直接上传。

## 通知

- 冷启动请求一次 `index.json`；从后台回到前台且离开超过 1 小时再请求一次；版本未变化时不下载正文。可在设置中关闭自动检查。
- 管理员通知（`note.md`）与开发者通知（`dev-note.md`）使用同一套版本比对；正文在底部面板用自研 Markdown 渲染器展示（标题、列表、引用、粗斜体、行内代码、代码块、链接、分隔线）。
- 管理员通知编辑器提供「今日考勤情况」「调休计划」模板，正文取本地实时统计；发布后写入待上传队列并本地预览，未接入签名上传前不伪造成功。
- 通知状态（已读版本、正文、最近检查结果、待上传草稿）随工作区持久化。

## 文件和密钥

导入支持第一张工作表 .xlsx 或 UTF-8 CSV，首行为“姓名”（也接受 name / 人员），同名和空姓名逐行提示并跳过，其余名单确认后新增。暂不处理旧版 .xls。

导出遵循当前搜索与筛选结果，可勾选列。所有单元格以文本写入，避免姓名/备注被识别为公式；第二张表记录应用、生成时间、记录数和时区规则。

两项对象存储密钥独立写入 flutter_secure_storage，不保存在 SQLite 和导出文件。Endpoint 网络探测仅返回 HTTP 状态；不发送密钥，不冒充完整鉴权测试。

## 自适应和验证

首页在可用宽度达到 720 时把概览与快捷入口切为双栏；窄屏 diff 可横向滚动。运行中跳过前 30 帧后，在前 90 帧累计至少 15 帧栅格化耗时超过 24ms 时会话内自动降级磨砂效果，不影响业务状态。

运行 `flutter analyze`、`flutter test` 与 Android debug 构建。原生文件选择 / 分享、系统安全存储建议在目标真机人工验收；`--dart-define=DEMO_SEED=true` 可生成一组演示人员、记录、请假与通知用于界面检查（默认关闭）。
